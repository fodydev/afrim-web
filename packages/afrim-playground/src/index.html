How it works

  1. Choose your language and an exercise.
  2. With Afrim keyboard on, type Latin letters: they turn into your writing system. The hint under the text shows what to type next.
  3. Already have a keyboard for your language? Turn Afrim off and use yours.
  4. Green is right, red is wrong. Use Backspace to fix mistakes.

Afrim shortcuts

Pause / Resume Ctrl Left + Ctrl Right
Clear input Escape or Space
Previous suggestion Ctrl + Shift Left
Next suggestion Ctrl + Shift Right
Use selected suggestion Ctrl + Space
